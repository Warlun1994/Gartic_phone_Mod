────────────────────────────────────────────────────────────────────
ЧАСТЬ 1. ИНСТРУКЦИЯ НА РУССКОМ
────────────────────────────────────────────────────────────────────

УСТАНОВКА
 1. Установите расширение Tampermonkey (Chrome/Edge/Firefox).
 2. Откройте панель Tampermonkey → «Создать новый скрипт».
 3. Удалите шаблон, вставьте всё содержимое файла
    gartic-phone-ui-layout-editor-2-19-0.user.js и сохраните (Ctrl+S).
 4. Откройте https://garticphone.com/ — скрипт заработает автоматически.

ГЛАВНЫЕ КНОПКИ (правый верхний угол)
 ⚙  UI  — открыть/закрыть панель редактора. Активная кнопка светится
          фиолетовым (так же подсвечиваются 🎨, 🖼 и 👥 при открытии).
 👥     — список игроков (подробнее ниже).
 🎨     — цветовой круг.
 🖼     — окно референса (картинка по ссылке или файлу).

ВКЛАДКА «РАСКЛАДКА»
 • Выберите элемент в списке или включите режим редактирования
   (кнопка 🖱) и кликните по элементу игры.
 • Меняйте X, Y, ширину, высоту, скрытие. Рядом с полями есть
   стрелки ▲▼◀▶ (крестовина): один клик — сдвиг на 1 пиксель,
   зажатие — плавное повторяющееся движение.
 • Кнопки верхнего ряда (⚙ UI, 👥, 🎨, 🖼) — одного размера,
   расстояние между ними настраивается ползунком «Зазор».
 • Простое/расширенное меню влияет ТОЛЬКО на список элементов:
   в простом показываются Холст, Верхняя панель, Панель инструментов,
   Цветовая панель, Кнопка «Готово», Раунд, Таймер; в расширенном —
   все элементы. Игру этот переключатель не скрывает.

СПИСОК ИГРОКОВ (кнопка 👥)
 • Список строится в реальном времени (по данным сети игры), как
   родной список игры, и работает и в лобби, и во время раундов.
 • Жёлтая метка — новый игрок (ещё не играл с вами). Метка снимается
   после одного сыгранного хода.
 • Без метки — обычные игроки, уже игравшие с вами.
 • Красная метка — игрок, чьи рисунки вы заблюрили.
 • Синяя метка (внизу, раздел «Ожидание») — игроки, подключившиеся
   во время игры.
 • Красный крестик ✕ рядом с ником — включить/выключить блюр
   рисунков этого игрока. Блюр чисто визуальный (фильтр поверх
   картинки), игру и отправку рисунка не затрагивает.
 • Элементы игроков в лобби и на экранах подключения/выбора режима
   закрашиваются теми же цветами (жёлтый/красный/синий), при просмотре
   альбома — тоже.

КИСТЬ / НАЖИМ / ПРОЧЕЕ
 • Вкладка «Рисование»: курсор кисти, тонкая кисть, нажим пера.
 • Вкладка «Оформление»: тема, фоны, свои шрифты и CSS.
 • «Диагностика» — технический отчёт (при проблемах).

АВАРИЙНЫЙ СБРОС
 Ctrl+Alt+Shift+0 — сброс, если свой CSS скрыл редактор.

PART 2. USER GUIDE IN ENGLISH
────────────────────────────────────────────────────────────────────

INSTALLATION
 1. Install the Tampermonkey extension (Chrome/Edge/Firefox).
 2. Open the Tampermonkey panel → "Create a new script".
 3. Delete the template, paste the whole contents of
    gartic-phone-ui-layout-editor-2-19-0.user.js and save (Ctrl+S).
 4. Open https://garticphone.com/ — the script starts automatically.

MAIN BUTTONS (top right corner)
 ⚙  UI  — open/close the editor panel. The active button glows
          purple (🎨, 🖼 and 👥 glow the same way when open).
 👥     — players list (see below).
 🎨     — color wheel.
 🖼     — reference window (image by URL or file).

"LAYOUT" TAB
 • Pick an element from the list, or enable the editing mode
   (🖱 button) and click a game element.
 • Change X, Y, width, height, visibility. Next to the fields there
   are ▲▼◀▶ arrow buttons (a D-pad): one click moves the element
   by 1 pixel, press and hold repeats the movement.
 • The top-row buttons (⚙ UI, 👥, 🎨, 🖼) are the same size; the
   spacing between them is set with the "Gap" slider.
 • Simple/advanced mode affects ONLY the element list: in simple mode
   you see Canvas, Top panel, Tool panel, Color panel, the "Done"
   button, Round and Timer; in advanced mode — all elements.
   The toggle never hides anything in the game itself.

PLAYERS LIST (👥 button)
 • The list is built in real time (from the game's network data),
   like the game's native list, and works both in the lobby and
   during rounds.
 • Yellow mark — a new player (has not played with you yet). The mark
   is removed after they play one turn.
 • No mark — regular players who already played with you.
 • Red mark — a player whose drawings you blurred.
 • Blue mark (bottom, "Waiting" section) — players who joined in the
   middle of a game.
 • The red cross ✕ next to a nickname toggles the blur of that
   player's drawings. The blur is purely visual (a filter over the
   picture) and never touches the game or the drawing upload.
 • Player elements in the lobby and on the connection/mode-selection
   screens are painted the same colors (yellow/red/blue); album
   entries are marked too.

BRUSH / PRESSURE / MISC
 • "Drawing" tab: brush cursor, thin brush, pen pressure.
 • "Appearance" tab: theme, backgrounds, custom fonts and CSS.
 • "Diagnostics" — a technical report (use it if something breaks).

EMERGENCY RESET
 Ctrl+Alt+Shift+0 — reset if your custom CSS hid the editor.
